# Rollback Pipeline

Rollback Pipeline은 배포 실패 또는 운영 장애가 발생했을 때 이전 안전 상태로 되돌리는 흐름이다.

## 트리거

```text
health check 실패
smoke test 실패
오류율·핵심 메트릭 임계치 초과
승인된 수동 롤백
```

## 흐름

```text
장애 범위 확인
→ 배포·데이터 변경 분리 판단
→ 이전 애플리케이션 산출물 복구
→ health check·smoke test
→ 결과·잔여 위험 기록
```

데이터베이스 마이그레이션은 애플리케이션 롤백과 별도로 판단한다. 파괴적인 데이터 변경은 자동 롤백하지 않고 복구 절차와 데이터 영향 확인을 우선한다.
