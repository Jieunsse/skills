# 업무 흐름 매핑

선택한 도구 안에서만 공통 흐름을 사용한다. 이 표는 GitHub Issues와 Linear 사이의 필드 매핑이나 동기화 규칙이 아니다.

| 공통 상태 | GitHub Issues | Linear |
| --- | --- | --- |
| Backlog | 대기 이슈 | Backlog |
| Ready | 준비 완료 라벨 또는 프로젝트 상태 | Todo |
| In Progress | 진행 중 라벨 또는 프로젝트 상태 | In Progress |
| In Review | PR 연결 상태 | In Review |
| Done | Closed | Done |

프로젝트는 선택한 열 하나만 적용한다. 프로젝트별 예외는 해당 composition에서 명시한다.
