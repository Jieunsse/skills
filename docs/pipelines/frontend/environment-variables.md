# 프론트엔드 환경 변수

## Next.js

- `NEXT_PUBLIC_` 접두사가 붙은 값은 브라우저 공개값으로 취급한다.
- 접두사가 없는 값은 서버 전용으로 취급한다.
- 공개값은 빌드 결과에 포함될 수 있으므로 비밀값을 넣지 않는다.

## React + Vite

- `VITE_` 접두사가 붙은 값은 브라우저 공개값으로 취급한다.
- `VITE_` 변수에는 비밀값을 넣지 않는다.
- 비밀값은 백엔드 또는 서버 함수에서 관리한다.

## `.env.example` 작성

```env
NEXT_PUBLIC_API_URL=
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

Vite 구성에서는 공개 변수 이름을 `VITE_`로 맞춘다. 변수명, 용도, 필요한 환경은 문서로 설명하되 실제 값은 기록하지 않는다.

## 검증

환경 변수 누락은 애플리케이션 시작 또는 CI 빌드 단계에서 확인한다. 환경 변수 변경 후에는 개발 서버나 배포를 다시 실행한다.
