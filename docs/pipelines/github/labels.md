# GitHub 라벨 체계

라벨은 `github-issues` 프로파일에서 이슈 유형, 우선순위, 계층을 구분하는 데 사용한다.

권장 분류:

```text
type:feature   type:bug   type:task   type:docs
priority:p0    priority:p1    priority:p2    priority:p3
layer:frontend  layer:backend  layer:mobile  layer:shared
```

라벨은 업무 상태를 유일하게 표현하는 수단으로 사용하지 않는다. `linear` 프로파일을 선택한 프로젝트는 Linear의 상태·라벨 체계를 기준으로 관리하며, GitHub 라벨은 코드 분류 용도로만 쓴다.
