# 코드베이스 확인단

코드베이스 확인단의 목적은 구현 속도가 아니라 잘못된 가정으로 코드를 수정하지 않는 것이다.

## 확인 순서

```text
프로젝트 지침
→ 디렉터리 구조
→ 실행 진입점
→ 도메인·모듈 경계
→ 데이터·API 흐름
→ 테스트 구조
→ 최근 변경 내역
→ 작업 영향 범위
```

## 확인 항목

- 루트와 하위 디렉터리의 `AGENTS.md`, `CLAUDE.md`, 규칙 파일
- 루트 및 계층별 `docs`
- 패키지 매니저, 실행 명령, 빌드 명령
- 애플리케이션 진입점과 주요 의존성
- 모듈·도메인 경계와 의존 방향
- 상태 관리, 데이터 fetching, API 계약
- 환경 변수와 외부 서비스 연결
- 기존 테스트와 테스트 실행 명령
- 최근 커밋과 현재 작업 트리의 미완성 변경
- 수정 대상의 호출자·소비자와 예상 회귀 범위

## 작성 전 산출물

```text
작업 목적
영향받는 파일·모듈
변경하지 않을 영역
재사용할 기존 구현
필요한 검증 방법
```

도메인 용어가 모호하거나 문서와 코드가 충돌하거나 검증 기준이 없으면 구현 전에 그 불일치를 해결한다.
