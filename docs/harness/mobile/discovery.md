# 모바일 확인단

공통 코드베이스 확인단에 다음 항목을 추가한다.

- Expo SDK와 app config
- iOS·Android 플랫폼 차이
- 네비게이션과 딥링크
- API, 인증, 토큰 저장 방식
- 카메라·위치·알림·파일 권한
- 네트워크 실패와 오프라인 상태
- 앱 버전, EAS Build, 스토어 배포 영향
- 환경 변수의 공개 범위
- 네이티브 모듈과 Expo managed workflow 호환성

## 종료 조건

- 영향을 받는 플랫폼과 권한을 확인했다.
- Expo managed workflow 호환성을 확인했다.
- 기기 또는 빌드 검증 필요 여부를 결정했다.
- 인증·API·배포 영향이 기록됐다.
