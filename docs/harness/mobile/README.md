# 모바일 Harness

모바일 Harness는 React Native, Expo, TypeScript에 필요한 공통 Harness Run의 추가 규칙을 정의한다.

```text
공통 Harness Run
├── Discovery      + mobile/discovery.md
├── Implementation + mobile/implementation.md
└── Verification   + mobile/verification.md
```

모바일 UI, 인증, 권한, 네이티브 모듈, 딥링크, 배포 설정 변경이 포함되면 이 Harness를 적용한다.
