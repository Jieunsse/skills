# 모바일 검증단

공통 검증 게이트에 다음 변경 유형별 검증을 승격한다.

| 변경 유형 | 추가 필수 검증 |
| --- | --- |
| 권한 | 허용·거부·재요청 흐름 |
| 인증 | 토큰 만료, 로그아웃, 앱 재시작 |
| 네이티브 모듈 | iOS·Android 빌드 또는 기기 검증 |
| 딥링크 | 앱 설치·미설치·인증 상태별 흐름 |
| Push | 권한, foreground, background 처리 |
| API client | Orval 생성, typecheck, 네트워크 실패 처리 |
| 배포 설정 | Expo config, EAS Build 검증 |

하드웨어·OS 동작을 포함하는 변경은 단위 테스트만으로 완료하지 않는다. 필요한 플랫폼 빌드 또는 실제 기기 검증을 실행하지 못했다면 미실행 사유와 잔여 위험을 `Verification Report`에 기록한다.
