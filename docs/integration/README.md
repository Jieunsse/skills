# 외부 연결 규칙

현재 저장소는 애플리케이션 템플릿을 직접 보관하지 않는다. 다만 `scripts/scaffold.mjs`는 명시적인 `--execute`에서 공식 생성기를 실행할 수 있다. 추후 필요한 템플릿·스크립트·도구를 생성 프로젝트에 연결할 때는 다음 정보를 문서화한다.

- 이름과 목적
- 외부 위치
- 버전 또는 커밋
- 대상 프로젝트 프로파일
- 설치 위치
- 연결할 설정 파일
- 실행 순서
- 검증 명령
- 업데이트와 롤백 방법

원격 리소스는 버전을 고정하고 출처를 기록한다. 자동 다운로드는 반복 수요와 검증이 확인된 뒤 구현한다.
