# 문제 정의 루프

문제 정의 루프는 증상과 구조적 원인을 구분하고 해결할 문제를 확정한다.

## 흐름

```text
관찰
→ 증상 정리
→ 구조적 원인 탐색
→ 영향받는 대상 확인
→ 문제 정의 수정
→ 해결할 문제 확정
```

## 산출물

- 문제 정의
- 증상과 원인 구분
- 영향받는 사용자·시스템
- 해결하지 않을 범위
- 검증할 가설

## 종료 조건

- 해결할 문제가 한 문장으로 설명된다.
- 증상과 원인이 구분된다.
- 영향을 받는 대상이 확인된다.
- 해결하지 않을 문제와 범위가 구분된다.

관련 스킬은 `problem-definition`이다.
