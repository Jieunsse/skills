# 제품 기획 루프

제품 기획 루프는 아이디어를 실행 가능한 요구사항과 작업 단위로 좁힌다.

## 흐름

```text
아이디어
→ 사용자·비즈니스 목표 확인
→ 가설 정의
→ 요구사항 작성
→ 우선순위 결정
→ 수용 기준 정의
→ 계획 확정
```

## 산출물

- 목표와 비목표
- 사용자·비즈니스 가설
- 요구사항
- 우선순위
- 수용 기준
- 작업 단위

## 종료 조건

- 성공 기준이 있다.
- 수용 기준이 있다.
- 요구사항을 작업 단위로 나눌 수 있다.
- 구현 전에 확인할 미결정 사항이 없다.

관련 스킬은 `pm-skills`이며, 업무 등록과 상태 관리는 선택한 GitHub Issues 또는 Linear 파이프라인에서 관리한다.
