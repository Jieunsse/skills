# 아키텍처 피드백 루프

아키텍처 피드백 루프는 현재 구조의 병목과 결합을 확인하고 작은 개선을 반복한다.

## 흐름

```text
현재 구조 관찰
→ 문제·병목 식별
→ 개선안 제안
→ 영향 분석
→ 작은 범위 적용
→ 검증
→ 다음 개선 결정
```

## 산출물

- 현재 구조와 문제
- 개선 목표
- 영향 범위
- 선택한 개선안과 대안
- 적용 결과
- 다음 개선 여부

전체 구조를 한 번에 교체하지 않는다. 변경 가능한 작은 단위로 나누고, 각 변경의 검증 결과를 확인한 뒤 다음 개선을 결정한다.

관련 스킬은 `archify`이며, 다이어그램은 구조를 설명하는 수단이지 구현·검증을 대신하지 않는다.
