# 기획 스킬

제품 발견과 의사결정을 위한 스킬을 관리한다.

## 외부 출처

- [phuryn/pm-skills](https://github.com/phuryn/pm-skills)

아이디어 탐색, 가설·기회 구조화, 고객 인터뷰, 리서치, 전략·시장 분석, 우선순위, 실험, 지표, 출시·성장 계획에 사용한다.

기획 스킬의 결과물은 프로젝트 문서, 이슈, Linear 작업 또는 composition의 입력으로 연결할 수 있다.

문제 정의가 필요한 경우 공통 스킬인 [`problem-definition`](../shared/problem-definition.md)을 먼저 사용하고, 이후 제품 발견·전략 스킬로 연결한다.
