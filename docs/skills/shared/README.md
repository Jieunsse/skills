# 공통 스킬

모든 프로젝트와 계층에서 사용할 수 있는 엔지니어링 스킬을 관리한다.

## 외부 출처

- [mattpocock/skills](https://github.com/mattpocock/skills)
- [obra/superpowers](https://github.com/obra/superpowers)

두 출처는 프로젝트 정렬, 설계, 계획, TDD, 디버깅, 리뷰처럼 특정 계층에 종속되지 않는 작업에 연결한다.

개인 정의 공통 스킬인 [`problem-definition`](problem-definition.md)은 기획이나 구현 전에 문제를 구조화하는 단계에 사용한다.

맷 포콕 스킬의 아이디어→PRD→이슈→TDD→아키텍처 개선 흐름은 [`mattpocock-workflow.md`](mattpocock-workflow.md)에 기록한다.
