# Skills

스킬은 사람과 AI가 작업을 수행하는 방법과 판단 기준을 문서화한다.

```text
docs/skills/
├── shared/
├── product/
├── design/
├── frontend/
├── backend/
└── mobile/
```

각 스킬 문서는 목적, 적용 조건, 입력, 작업 규칙, 결과, 검증 방법을 포함한다. 실제 실행 스크립트는 포함하지 않는다.

외부 출처와 적용 범위는 [`catalog.md`](catalog.md)에서 관리한다.

공통 시각화 스킬인 [`archify`](shared/archify.md)는 아키텍처와 업무 흐름을 표현할 때 사용한다.
