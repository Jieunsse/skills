# 프론트엔드 스킬

웹 프론트엔드 계층에서 사용하는 스킬을 관리한다.

## React·Next.js

- 출처: [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills)
- 경로: `skills/react-best-practices`
- 표준 이름: `vercel-react-best-practices`
- 적용 대상: React, Next.js 코드 작성·리뷰·리팩터링

이 스킬은 프레임워크 선택을 대신하지 않는다. `docs/model/frontend-stack-selection.md`가 목적별 프레임워크를 선택하고, 이 스킬은 선택된 구성의 구현 품질을 담당한다.

코드 작성 시 [`code-quality.md`](code-quality.md)의 가독성, 예측 가능성, 응집도, 결합도 규칙을 함께 적용한다.
