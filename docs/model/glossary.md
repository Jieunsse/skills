# 용어집

## 저장소

이 문서 저장소 자체와, 이 저장소를 사용해 새로 생성하는 프로젝트 저장소를 구분한다.

## 구역

재사용 지식을 책임별로 나눈 운영 영역이다.

- `skills`: 작업 지식과 판단 규칙
- `harness`: 한 작업의 코드베이스 확인·작성·검증 기준
- `loops`: 반복 개발 방식
- `pipelines`: 이슈·PR·CI·배포를 연결하는 작업·운영 흐름

## 기술 계층

프로젝트 안에서 기술적 책임을 나누는 단위다.

- `frontend`: 웹 프론트엔드
- `backend`: 백엔드와 API
- `mobile`: React Native + Expo 모바일 앱

## 저장소 프로파일

프로젝트 저장소의 형태다.

- `frontend-only`: 프론트엔드 단독 저장소
- `backend-only`: 백엔드 단독 저장소
- `monorepo`: 여러 애플리케이션을 하나의 저장소에서 관리

## 스캐폴딩

프로젝트를 만들 때 필요한 디렉터리, 문서, 규칙, 도구 연결을 정의한 명세다. `composition`은 선택과 명세를, `scripts/scaffold.mjs`는 공식 생성기 실행과 기본 문서 배치를 담당한다.

## composition

스킬·하네스·루프·파이프라인·배포·업무 관리 프로파일을 특정 프로젝트 형태에 맞게 조합한 구성 명세다.

## 이슈 관리 프로파일

프로젝트 업무를 관리하는 도구와 운영 방식을 정의한다.

- `github-issues`
- `linear`

## MCP

외부 도구를 AI 작업 환경에 연결하는 실행·통합 계층이다. 연결과 권한은 `harness/mcp`, 활용 방법은 관련 `skills`와 `pipelines`에서 관리한다.

## DDD

도메인 경계를 중심으로 코드를 구성하는 방식이다. 이 저장소의 백엔드 기본 폴더 구조는 도메인별 최상위 패키지와 그 내부의 `domain`, `application`, `adapter`로 구성한다.
